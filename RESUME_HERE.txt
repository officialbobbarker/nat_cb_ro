PROJECT GOAL
==============================================================================
Identify when each of the largest US public school districts adopted 1:1
student devices (Chromebooks, iPads, laptops). The hypothesis is that the
shift from pen-and-paper to personal device use during class is an important
inflection point in education strategy. We want to capture WHEN it happened
for as many of the largest districts as possible.

Districts ranked by SEDA mean grade-3 enrollment (computed from
seda_district_covariates_long.csv). The top 30 used a different size metric
in the seda_row_count column — see CAVEATS below.

COLUMNS (current schema, 15 columns)
==============================================================================
1. district_name      — official district name
2. state              — 2-letter state abbreviation
3. city               — primary city
4. year_started       — 4-digit year, "2020 (by)" / "2014 (by)" upper bound,
                        or blank
5. month_started      — month name, "Spring"/"Fall", or blank
6. one_to_one         — Yes / Yes (phased) / Yes (likely) / Partial / etc.
7. grade_levels       — grades covered (free-text)
8. device_type        — Chromebook / iPad / Laptop / Mixed / etc.
9. notes              — free-text rationale, sources cited, caveats
10. source_url        — primary source URL
11. source_2          — secondary source URL (or blank)
12. seda_rank         — integer 1-300 (largest = 1)
13. seda_row_count    — size metric (mean grade-3 enrollment for ranks 31+;
                        original cellcount metric for ranks 1-30 — see
                        CAVEAT (A))
14. web_search        — 1 if a web search has been done for this district,
                        0 otherwise. Currently 1 for all 300 rows (every
                        row has web-search evidence in source_url and/or
                        notes).
15. fb_search         — 1 if the district's Facebook page has been searched
                        using the strategy.txt FB-profile-search method,
                        0 otherwise. Currently 1 for exactly 4 rows
                        (ranks 1, 2, 3, 11 — NYC, LAUSD, Chicago,
                        Hillsborough). Heuristic for the retroactive flag:
                        source_url or source_2 matches
                        `facebook\.com/profile/.*search`. A row with a
                        regular facebook.com post URL (e.g., rank 255
                        Shelby AL) is NOT considered an FB search — that's
                        a web-search hit that happened to land on a FB
                        post.

For new rows added going forward: set web_search=1 once you've done the
WebSearch queries listed in the agent prompt template. Set fb_search=1
only if you actually open the district's facebook.com/profile/<id>/search/
page and read results, per the FB methodology in research_strategy.txt.
fb_search is the more thorough method — most useful for "2020 (by)" upper
bound rows where pre-pandemic launch year couldn't be pinned via news.

HOW TO IDENTIFY THE NEXT DISTRICTS TO RESEARCH
==============================================================================
The deduplicated, ranked list of largest districts comes from awk on the
SEDA covariates file. To regenerate the ranking:

   cd C:/Users/mjensen6/Documents/claude_box/tech_in_schools/national
   awk -F, 'NR>1 && $4==3 && $29!="" {
       gsub(/"/,"",$1); gsub(/"/,"",$2); gsub(/"/,"",$6);
       key=$1"|"$2"|"$6; sum[key]+=$29; n[key]++
   } END {
       for (k in sum) printf "%d\t%s\n", sum[k]/n[k], k
   }' seda_district_covariates_long.csv | sort -rn > /tmp/all_ranked.txt

That gives mean grade-3 enrollment per (leaid, leaname, state). Many
districts appear under MULTIPLE alias names (e.g., "LOS ANGELES UNIFIED"
vs "LOS ANGELES UNF") — same leaid, different name. Dedup by leaid
when picking the next batch. The covariates file uses leaid as a 7-digit
numeric (sometimes with a leading 0 stripped), so build your "covered"
filter with BOTH zero-padded and zero-stripped variants for CA/AZ/CO/UT
districts (state code 04, 06, 08, 49 — leaids look like "0634170" or
"634170" depending on source).
